# 数学建模论文模型图示与科研数据可视化规范

> control_id: `PW-FIG-001`
>
> 适用范围：CUMCM 及同类数学建模论文中空间场图、全对象指标图、候选解或优化结果图、几何模型图，以及一般数据图、诊断图、地图、原理图、流程图、技术路线图、结构图、网格图和多面板组合图的选择、生成、叙事、排版、导出与视觉审校。
>
> 核心原则：**先明确图片的论证职责与来源；图型依次服从合理的用户明确指定、模型原生结构和通用统计选择；按论文最终显示尺寸生成，并以最终 PDF 中的真实阅读效果作为通过依据。**

本文件是论文图片与科研可视化要求的唯一权威。表格、正文结构、公式、通用字体和参考文献由 `docs/standards/paper-writing.md` 管理；图片产物路由、证据、复现、匿名性和发布工程由 `docs/standards/workspace-governance.md` 管理；审查报告与竞争力评分由 `docs/standards/paper-quality-audit.md` 管理。其它文件只引用 `PW-FIG-001`，不得维护第二套图型阈值、图片比例、分辨率、字号或视觉检查规则。

---

## 0. 优先级与硬规则

- **必须 / 不得**为发布硬要求，未满足时按第 10 节判断 `BLOCKED`；**应 / 原则上**为默认要求；**宜 / 推荐**为质量建议；**可**表示允许。
- 冲突时依次服从：当届官方或赛区规则、用户当前明确要求、赛题输出要求、本规范、绘图软件默认值。
- 图型决策依次为：**合理的用户明确指定 → 模型原生结构 → 通用统计选择**。本规范的“首选”“推荐”“原则上不使用”只约束 Agent 自主选图，不得作为拒绝用户要求的依据。
- 用户指定图型只要无事实或数学错误、数据维度支持、不产生严重误导且不违反官方硬规则，就应生成；有可化解风险时“简要提示—优化实现—仍按要求生成”。仅在用户指定图型的选型阶段，上述四类硬冲突才构成拒绝理由；发布阻断另按第 10 节执行。拦截的是错误编码，不是图型名称。

## 1. 图片职责

论文图片分为三类：

1. **数据与结果图**：呈现趋势、分布、关系、比较、空间格局、预测、权衡、误差、稳定性或收敛性。
2. **诊断与验证图**：呈现残差、真实值—预测值、ROC/PR、混淆矩阵、敏感性、置信区间、网格无关性、守恒或边界检查。
3. **解释性图示**：解释技术路线、几何关系、物理机理、模型结构、算法步骤、网络、网格、分支和循环。

每张图必须服务一个明确论点、处理决定、模型关系或验证结论，不得凑数量、凑图型或装饰页面。图示不替代公式推导、算法说明、数值指标或直接答案；流程图、代码截图和软件界面不得冒充模型结果。

- 仅凭曲线“看起来接近”不得宣称模型准确、稳定或正确，须配合数值指标、统计量或明确判据。
- 精确数值优先用表，趋势、分布、关系、空间格局和权衡优先用图；同一信息不在正文、图和表中三次完整重复。
- 数据预处理图必须支持明确的处理决定，不对每一列机械作图。

## 2. 工作流

正式项目应将 `resources/templates/figure-selection-record.md` 复制为 `00-admin/figure-selection-record.md`，按候选图片记录论证目标、用户指定、数据或模型结构、候选比较、视觉编码、生成路径和审校结论；新项目由初始化脚本自动复制。该记录用于执行与追踪，不替代图片、程序输出、证据索引或最终 PDF 审查。

1. 明确用户要求与论证职责，说明图片支撑的子问题、主张或处理决定。
2. 核对数据、参数、模型输出或结构定义的权威来源，以及单位、范围、分组和筛选口径。
3. 完成第 3.1 节剖析并识别第 3.2 节模型原生结构。
4. 按第 0 节三级原则选图，并先确定论文中的最终显示尺寸、布局和输出格式。
5. 从最终数据或模型定义生成并标注，完成第 9 节三层检查。
6. 检查通过后导出、路由、登记证据并同步正文引用。

论证职责、数据口径或最终显示尺寸实质变化时，原选择与审查结论失效，必须按变化类型重新选择或生成并重新审查。

## 3. 图型选择

### 3.1 数据剖析

数据图至少核对：

- 变量类型、含义、单位、范围、样本量和分组；
- 缺失、重复、异常、偏态、多峰和数量级差异；
- 自变量的连续性、顺序、时间或空间属性及对象间依赖；
- 原始值、处理值、汇总值、预测值或仿真值的口径；
- 是否存在模型原生结构，以及论证需要保留全量对象还是展示分布、不确定性或关系。

数字 ID、对象编号和类别编码不得仅因由数字组成就当作连续变量；但当论证目标是展示全部对象或候选解时，可将对象或解编号作为枚举索引轴，不得因此自动聚合，也不得用连线暗示不存在的连续插值关系。跨数量级数据使用对数轴、分面或标准化时，必须有实际理由并在图题或正文说明。

### 3.2 模型原生结构

空间坐标、真实二维或三维位置、几何边界、网格、路径、方向、网络拓扑、仿真时刻、迭代次数、候选解或随机解编号、模型对象编号、场变量，以及模型中的点、线、面、区域和交集，均属于模型原生结构。当用户未指定其它合理图型，且这些结构参与模型解释、结果判断或结论论证时，**必须优先在原生结构上直接可视化**。

| 模型原生结构 | 优先表达 | 必须保留或标注 | 应避免 |
|---|---|---|---|
| 空间坐标或空间标量场 `(x_i,y_i,v_i)` | 真实坐标散点或颜色散点；网格或插值条件成立时可用等高线、云图、网格场、热力图或科学三维曲面 | 连续指标的色标须含变量名和单位；距离有几何意义时保持 `axis equal` 或等效比例 | 脱离位置后按 `v_i` 排序成柱状图，或为版式扭曲空间比例 |
| 候选解、随机可行解、Monte Carlo 解或多次仿真 | `solution index - objective` 散点、stem、细竖线、点阵或全候选解图；突出最优点，并可用水平虚线标出基准或最优值 | 保留解级结果及目标函数口径 | 论证目标并非统计分布却自动汇总为均值、箱线图或柱状图 |
| 数百至数千个模型对象的逐对象指标 | `object id - metric` 全量点图、stem、细竖线或高密度序列 | 覆盖、周期、波动或局部异常本身是证据时保留全量对象 | 仅因点多而自动抽样、聚合或排名压缩 |
| 几何、遮挡、交叠、投影或可行区域 | 按模型定义和公式直接绘制坐标轴、点线面、边界、顶点、交点、方向、交叠或遮挡区域 | 符号、坐标变换与正文公式一致；真实距离有意义时保持几何比例 | 用“计算遮挡→计算效率”等通用流程框图替代实际几何关系 |

- 时间或迭代过程优先使用过程曲线；
- 网络拓扑优先使用网络图；
- 真实三维空间、三变量关系或 `z=f(x,y)` 响应面可使用二维颜色/分面或具有实际第三维含义的科学三维图。

Agent 自主选图时，不得仅为图形“干净”、风格统一或符合通用统计习惯，先对需要保留的原生结果进行 `groupby`、求均值、排名、聚合、抽样或压缩。只有不存在需要保留的模型原生结构，或论证目标本身就是统计分布时，才进入通用统计图型选择。

### 3.3 通用图型表

本表用于用户未指定图型、且没有需要保留的模型原生结构时的自主选择。“条件使用 / 次选”表示有合适语义时可以使用，不是禁止项。

| 论证目的或数据结构 | 首选表达 | 条件使用 / 次选 | 应避免 |
|---|---|---|---|
| 缺失模式 | 缺失矩阵或缺失比例图 | 按变量分面 | 为每列重复生成无结论图片 |
| 单个连续变量的分布 | 直方图、经验分布图或箱线图 | 必要密度线、小提琴图 | 用饼图表示连续分布 |
| 组间比较、分类自变量下的连续结果、异常值或离散程度 | 点图、箱线图配个体点，或带明确区间的点图 | 样本与不确定性口径齐全的柱状图、小提琴图 | 只有均值且不交代个体或分布 |
| 类别数量比较 | 排序横向柱状图或点图 | 堆叠柱状图 | 用面积、角度或透视妨碍精确比较 |
| 部分—整体构成 | 排序柱状图或堆叠柱状图 | 各部分同属明确整体、总和有意义（通常为 100%）、原则上不超过 5～6 类且重在构成的普通二维饼图 | 三维或透视饼图、无意义爆炸、类别过多或不构成整体的饼图 |
| 时间、日期、距离、剂量、温度、参数、迭代或其它有序过程 | 折线图配必要误差带 | 散点图、stem 或阶梯图 | 给无序类别强行连线并制造趋势 |
| 两个连续变量的关系 | 散点图配必要拟合线、区间和相关统计量 | 二维密度或六边形分箱 | 把无序样本连成折线 |
| 三变量关系 | 二维散点配颜色、大小编码或分面 | 第三维真实且有解释价值的三维散点图 | 虚构 z 轴或仅为“高级感”增加透视 |
| 多变量相关关系 | 相关热力图或散点矩阵 | 经筛选且维度可读的平行坐标图 | 无筛选的高维堆叠 |
| 分类效果 | 混淆矩阵、ROC 或 PR 曲线 | 分面比较 | 只给单一准确率 |
| 回归拟合与误差 | 真实值—预测值图、残差图和误差分布 | 带区间的拟合曲线 | 只给一条平滑拟合曲线 |
| 少量方案排名或多指标画像 | 三线表配柱状图或点图 | 维度少、尺度可比或已合理归一化的雷达图 | 指标过多、尺度不一致或多方案堆叠的雷达图 |
| 参数敏感性 | 参数—结果曲线或区间图 | 龙卷风图 | 只给单个扰动点 |
| 多目标权衡 | Pareto 前沿 | 分面或可读的平行坐标图 | 用任意加权总分掩盖权衡 |
| 算法、机理或非几何结构 | 与职责匹配的流程图、原理图或结构图 | 多面板组合 | 软件界面、代码截图 |

图例类别或分组组合超过 12 个、单图承担不相干结论或主次难辨时，应按结论主题拆图。统一字体、颜色语义、线宽和版式风格，不得把不同模型结果机械改成同一种统计图型。

### 3.4 少量硬性禁区

1. 每组 `n < 10` 时不得只画均值柱；必须展示个体点，可使用点图或箱线图配个体点。
2. 无部分—整体关系的饼图、三维或透视饼图、无意义爆炸式饼图应拦截；类别较多或比例接近属于表达风险，用户明确指定普通二维饼图且不构成严重误导时按第 0 节处理。
3. 禁止虚构 z 轴、立体厚度或仅为装饰的伪三维，不禁止具有真实第三维、空间坐标或几何含义的三维散点、曲面、轨迹、网格和结构图。
4. 无序类别或样本不得用折线制造连续关系；具有自然顺序或连续含义的横轴可以使用折线。
5. 不得用平滑、汇总、聚合或抽样掩盖与论证有关的信息，也不得移动数据点、修改坐标、删除不利样本或更改标签。

## 4. 坐标、统计与颜色

- 凡适用且为正确解释所需，坐标、单位、刻度、图例、色标、时间与样本范围、筛选口径和分面标签必须齐全。
- 可比较的多图统一坐标与色标范围、颜色语义、类别顺序和统计口径；确需不同尺度时显式说明。同一对象跨图保持同一颜色、线型或点型，同一视觉变量不得表达相反含义。
- 与结论有关的最优点、基准、阈值、可行域或区间应直接标注且不得遮挡数据。
- 柱状图、面积图等以基线长度或面积编码数量时，数值轴原则上从 0 起；折线、散点、stem、误差图、时间序列和响应曲线等位置编码可采用非零下限，但范围须清楚且不得极端截断夸大差异。断轴、对数轴或其它尺度变换须显著标示并说明理由。
- 空间场、地图和几何图中，x、y 距离具有真实意义时须保持 `axis equal` 或等效比例。
- 只有过绘制遮蔽目标结构时，才使用透明度、密度、六边形分箱、分面、抽样或聚合并说明口径；全量覆盖、高密度、周期、空间分布、候选解或局部异常本身是证据时保留全量。
- 原则上避免双 Y 轴比较不同变量；优先使用共享 x 的上下子图，或有依据地标准化后共轴比较。

论证涉及抽样、预测或参数不确定性时，应使用误差棒、置信带、分布图、箱线图或区间表，不得只给确定性中心线。图题或正文按实际情况说明误差或区间类型与样本量 `n` 的含义、实际使用的检验与校正、显著性阈值和必要的实验设计；不得混淆 SD、SEM 与置信区间，或仅用星号替代效应量和实际意义。

- 离散配色应高对比、色盲友好；连续量使用感知均匀的顺序色图，正负偏差使用有明确中点的发散色图。
- 连续颜色编码必须配置含变量名和单位的色标，不得用颜色范围改变数据含义或使用感知不均匀的 rainbow/jet 色图。
- 颜色只承担真实编码，不使用无意义渐变、阴影或装饰背景；重要类别采用线型、点型、纹理、直接标签或分面等冗余编码，并保证黑白打印可辨。

### 4.1 参考图驱动的审美校准

图型与视觉编码确定后，应使用 `resources/figure-style-library/` 中少量、与当前视觉问题相关的科研图片作为审美锚点。参考图只用于校准字体层级、轴线与刻度、克制配色、线宽与点大小、留白与边距、图例位置、注释密度以及多面板对齐和一致性；不得将其作为数据、模型、结论或图型选择依据。

- 科学正确性、合理的用户指定、模型原生结构和数据语义始终高于参考图风格；参考图不得触发无依据的平滑、汇总、排序、抽样、聚合、三维化或视觉夸张。
- 不得为模仿参考图而改变合理图型、坐标语义、尺度、统计量、不确定性表达、对象覆盖或几何比例；不存在合适参考时直接按本规范生成，不强行套用。
- 参考项须有可说明的来源与使用边界，并明确记录“可学习属性”和“不可复制内容”；来源不明、存在明显误导性编码或在最终尺寸下不可读的图片不得进入参考库。
- 同一组正式图片应从所选参考中提炼一套共享视觉语言，不得逐图照搬不同样例造成字体、颜色、线宽、边距、图例和面板标签失配。
- 参考图本身不得进入项目结果目录或充当证据。正式图必须由项目权威数据、程序或已核对的模型定义独立生成，并在最终显示尺寸下重新完成第 9 节审查。

具体选择、提取、记录与扩充方法见 `docs/guides/scientific-figure-aesthetics.md`；该指南与参考库不得维护或覆盖本文件的图型阈值、字号、分辨率及发布条件。

## 5. 几何和解释性图

涉及网络、多阶段、分支、循环或多个模型组件时，原则上配置匹配的结构图或流程图；空间几何、投影、遮挡、交集、可行域或边界参与推导或结论时，必须按模型定义直接绘制原生几何图。流程图只解释计算顺序，不得替代几何关系；简单关系用文字和公式已足够时，不添加装饰图。问题分析处可用技术路线图，模型建立处使用几何、原理或结构图，求解处使用算法流程图。

- 几何图直接表现坐标轴、对象、关键顶点与交点、边界、重叠或遮挡区域、方向和变量，符号与正文公式一致。
- 图中对象、箭头、坐标、方向、输入输出和术语须与模型或算法一一对应。
- 流程图须有清楚的入口、出口、主线、分支、回流和判断依据；避免无标记交叉、歧义连接和过长节点文字。
- 节点、箭头、连线和标签不得重叠、压线或遮挡；流程图不能替代必要的输入、输出、文字和公式。

## 6. 图题与论文叙事

图片遵循“前文引入目的—呈现图片—后文解释发现与作用”，靠近首次引用处且先引用后出现；同一结果图不在多章重复。结果部分先给答案或核心判断，再按“核心结果图—必要精确值表—验证或诊断图”展开，图后解释方向、数量级、原因或决策含义，不得只写“由图可知结果良好”。

1. 图题置于图下，统一为“图 x  标题”，图号连续且正文引用一致。
2. 图题应能独立说明对象、指标、条件、情景、样本或数据口径；多面板图还需说明各面板差异。
3. 正式论文中的普通单图默认不在图内用 `ax.set_title()` 或等效方式重复完整图题；图内主要保留坐标轴、单位、图例、色标、阈值、基准线和必要注释，完整标题交由图下图题管理。多面板图可保留“(a)”“(b)”及简短面板说明。
4. 图题与图片不得跨页拆散；字体、字号及图内中西文字体执行 `PW-FMT-001`，不保留绘图软件默认字体。
5. 图片文件名和稳定标签执行 `docs/standards/naming.md`。

## 7. 尺寸与排版

按论文最终显示尺寸设置画布、字号、线宽、点、箭头和图例；插入 Word/LaTeX 时只等比放置，尺寸变化影响可读性时须重绘。
画布比例依次服从：**真实几何比例 > 科学含义 > 信息容量与可读性 > 论文排版 > 黄金比例经验**。
`1.618:1` 仅在无更高约束时作为参考；空间场、地图、几何、网格和真实坐标三维图保持正确比例，全量对象序列可使用宽画布，不得为黄金比例扭曲或裁掉有效结构。

- 图内关键文字在最终尺寸下原则上不小于 **9 pt**，坐标、图例、色标、标注和节点须直接可读。
- 主线、辅助线、基准线、置信带和网格线保持清楚层级。
- 组合图原则上不超过 6 个子图；子图等宽等高、间距一致，并按阅读顺序统一标注“(a)”“(b)”。
- 共享坐标、图例或色标时只保留一套；同类图保持尺寸、字体、线宽、颜色和风格一致。
- 每张图须在论文实际尺寸下阅读检查；必须放大才能辨字或主线无法顺序阅读时，应重排、放大、拆图或删减文字。

## 8. 输出

1. 可准确表达且文件规模合理时，线图、散点图、stem、柱状图、误差图、几何图、流程图、结构图和一般热力图优先导出 PDF、SVG 或 EPS。
2. 照片、遥感、像素场、极高密度点、复杂曲面或栅格场使用 PNG 或 TIFF；正式数据图和示意图不得使用 JPEG。
3. 位图在最终插入尺寸下原则上不低于 **300 dpi**，必要时使用 600 dpi；改写 DPI 标签或转格式不能增加真实清晰度。
4. 自检可用 PNG 和灰度预览，正式图通过检查后再导出论文版本。
5. 图片必须由最终数据、程序或已核对的模型定义生成，不得使用软件界面截图或手工修改数据、坐标和标签。
6. 正式产物、论文副本和预览按 `docs/standards/workspace-governance.md` 路由；`06-paper/figures/` 只保存实际引用副本，临时预览不得作为唯一证据或交付物。文件属性和元数据不得暴露身份、本机用户名或路径。

## 9. 视觉审查

每张正式图须先渲染为 PNG 或页面预览，同时完成可程序检查与人工或具备视觉能力的 Agent 读图复核：


**语义层**

- 核对论证职责、来源和第 0—4 节的选图与编码要求；
- 确认用户合理指定已实现，模型原生结构未被无依据汇总、抽样或排序；
- 核对样本量、统计量、不确定性和显著性，以及图与正文和权威结果的一致性。

**形式层**

- 核对最终尺寸、比例、字体、字号、线宽、图号和图题；
- 核对适用的坐标、单位、图例、色标、面板标签、误差说明和注释；
- 核对格式、有效分辨率、留白、等比缩放、文件名、路由和匿名性。

**视觉层**

- 检查乱码、负号异常、越界、裁切、刻度重叠、遮挡和压线；
- 检查图例、色标、标注、节点、箭头、多面板对齐与阅读顺序；
- 检查灰度可辨性和正常打印尺寸下的视觉层级；
- 使用参考图时，检查只迁移了已记录的视觉属性，未复制不适用图型、数据、注释或结构，也未因模仿损害科学语义；
- 主要结构与结论可识别即可，有意义高密度不因无法逐点点名而失败。

**最终 PDF**

- 源图通过不等于论文中的图通过，发布前须逐页渲染拟交付 PDF；
- 在实际排版尺寸和 100% 显示下检查清晰度、比例、留白、分页和上下文；
- 确认无重叠、遮挡、裁切、压线、歧义、非等比拉伸或过度缩小；
- 核对正文引用、图题、数值、单位和结论与最终图一致。

任一层失败须返回生成步骤修改并重新渲染。图片、图题、分页或正文解释变化后，原审查结论失效；分页变化时重新检查全部页面。

## 10. `BLOCKED` 条件与发布检查

- 图片中的数据和事实主张必须满足 `WG-EVID-001`，并追溯到 `04-results/` 的权威结果、明确推导或已核验资料。
- `06-paper/figures/` 中的论文副本须追溯到正式图；摘要、正文、图、表、附录与机器结果的数值、单位、对象和舍入保持一致。

`BLOCKED` 只针对事实、数学、证据、严重误导或交付硬错误，不得因图型名称或不是默认首选而触发。

出现下列任一情况时，`PW-FIG-001` 必须判为 `BLOCKED`：

1. 来源或关键数值不可追溯，或图与正文、公式、表格、附录、机器结果不一致；
2. 存在事实或数学错误，或数据结构与维度不支持所用编码；
3. 尺度、颜色、统计量、连线、伪三维、几何比例、汇总或数据删改造成严重误导；
4. 缺少正确解释所必需的坐标、单位、图例、色标、误差定义、样本量或图题信息；
5. 最终 PDF 存在影响阅读的乱码、模糊、过小字号、重叠、遮挡、裁切、压线、歧义或非等比缩放；
6. 未完成最终 PDF 逐图复查，或修改后沿用已失效的审查结论。

发布前简短检查：

- [ ] 第 1—3 节的论证职责、来源与三级图型决策已落实。
- [ ] 第 4—8 节的语义、图示、叙事、排版、真实性与输出要求已满足。
- [ ] 第 9 节三层审查及最终 PDF 复查有效。
- [ ] 产物路由、证据、匿名性和跨载体一致，无上述阻断项；`PW-FIG-001` 可判为 `PASS`。
