# 数学建模论文图片与科研可视化规范

> control_id: `PW-FIG-001`
>
> 适用范围：CUMCM 及同类数学建模论文中数据图、结果图、诊断图、地图、几何图、原理图、流程图、技术路线图、结构图、网格图、多面板组合图的选择、生成、叙事、排版、导出与视觉审校。
>
> 核心原则：**先确定图片要证明什么，再依据数据与模型选择图型；按论文最终显示尺寸生成，并以最终 PDF 中的真实阅读效果作为通过依据。**

本文件是论文图片与科研可视化要求的唯一权威。表格、正文结构、公式、通用字体和参考文献由 `docs/standards/paper-writing.md` 管理；图片产物路由、证据、复现、匿名性和发布工程由 `docs/standards/workspace-governance.md` 管理；审查报告与竞争力评分由 `docs/standards/paper-quality-audit.md` 管理。其它文件只引用 `PW-FIG-001`，不得维护第二套图型阈值、图片比例、分辨率、字号或视觉检查规则。

---

## 0. 规范用语、优先级与通过条件

- **必须 / 不得**：硬性要求，未满足时 `PW-FIG-001` 为 `BLOCKED`。
- **应 / 原则上**：默认执行；题型确实不适用时，必须采用能完成同一论证职责的等效表达并说明理由。
- **宜 / 推荐**：质量提升项，结合题目和版面选择。
- **可**：允许但不强制。

发生冲突时依次服从：当届官方或赛区规则、用户当前明确要求、赛题输出要求、本规范、绘图软件默认值。本文中的尺寸、比例、格式和审校要求属于工作区质量增补，不冒充全国组委会统一规定。

`PW-FIG-001` 通过必须同时满足：图片有明确论证职责和可追溯来源；图型与数据结构匹配；语义、统计和视觉编码正确；版式与导出符合本规范；最终 PDF 已逐图完成语义层、形式层和视觉层检查，且不存在未解决的遮挡、裁切、乱码、误导性编码或正文不一致。

## 1. 图片职责与使用边界

### 1.1 图片类型

论文图片分为三类：

1. **数据与结果图**：呈现趋势、分布、关系、比较、空间格局、预测、权衡、误差、稳定性或收敛性。
2. **诊断与验证图**：呈现残差、真实值—预测值、ROC/PR、混淆矩阵、敏感性、置信区间、网格无关性、守恒或边界检查。
3. **解释性图示**：解释技术路线、几何关系、物理机理、模型结构、算法步骤、网络、网格、分支和循环。

每张图必须服务一个可明确表述的论点、处理决定、模型关系或验证结论。不得为凑数量、凑图型或装饰页面生成图片，也不得用流程图、结构图、代码截图或软件界面冒充求解结果。

### 1.2 图片不能替代的内容

- 图示只承担解释结构、关系、过程和结果的职责，不替代公式推导、算法文字、求解步骤、数值指标或直接答案。
- 仅凭曲线“看起来接近”不得宣称模型准确、稳定或正确；图形比较必须配合数值指标、统计量或明确判据。
- 同一信息不得在图片、表格和正文中三次完整重复。需要准确读取的数值优先用表，趋势、分布、关系、空间格局和权衡优先用图。
- 数据预处理图片必须支持一个明确处理决定，不得对每一列机械作图。

## 2. 图片生产工作流

正式项目应将 `resources/templates/figure-selection-record.md` 复制为 `00-admin/figure-selection-record.md`，按候选图片记录论证目标、数据剖析、候选比较、视觉编码、生成路径和审校结论；新项目由初始化脚本自动复制。该记录用于执行与追踪，不替代图片、程序输出、证据索引或最终 PDF 审查。

正式图片必须按以下顺序生产，不得从“用户指定了某种图”直接跳到绘制：

1. **确定论证目标**：用一句话写清图片要让读者相信什么，以及图片回答哪个子问题、支撑哪个主张或处理决定。
2. **核对来源**：定位数据、参数、模型输出或结构定义的权威来源，确认单位、筛选范围、样本范围、分组口径和证据状态。
3. **剖析数据或结构**：数据图先检查变量类型、样本量、缺失、分布、异常、分组、相关性和尺度；图示先核对对象、关系、方向、分支和正文术语。
4. **选择图型**：依据论证目的与数据结构给出首选图型、选择理由和必要备选；不合适的指定图型必须先指出风险并采用符合本规范的表达。
5. **确定最终版式**：先确定论文中的实际显示宽度、高度、单图或多面板布局、字体、颜色与输出格式，再按该尺寸绘制。
6. **生成与标注**：从最终数据或模型定义生成图，补齐坐标、单位、图例、色标、面板、阈值、区间和图题所需信息。
7. **三层自检**：依次完成语义层、形式层和视觉层检查；发现问题后回到对应步骤修改并重新渲染。
8. **导出与登记**：视觉检查通过后再导出正式格式，按工作区路由保存权威产物和论文引用副本，并同步证据与正文引用。

论证目标、数据口径或最终显示尺寸发生实质变化时，原图不得继续沿用，必须重新选择、生成或审校。

## 3. 数据剖析与图型选择

### 3.1 绘图前最低剖析要求

数据图至少核对：

- 每列的变量类型、单位、取值范围和实际含义；
- 总样本量、各组样本量及分组是否极不平衡；
- 缺失、重复、异常值、偏态、多峰和数量级差异；
- 自变量是否连续、有序、时间性或仅为类别；
- 变量关系、时间/空间依赖和可比较对象；
- 图片使用的是原始值、处理值、汇总值、预测值还是仿真值；
- 论证需要展示个体数据、中心趋势、分布、不确定性、关系还是精确数值。

数字 ID、对象编号和类别编码不得仅因由数字组成就当作连续变量。跨数量级数据使用对数轴、分面或标准化时，必须有实际理由并在图题或正文说明。

### 3.2 图型选择速查

| 论证目的或数据结构 | 首选表达 | 不得或不宜采用 |
|---|---|---|
| 缺失模式 | 缺失矩阵或缺失比例图 | 为每列重复生成无结论图片 |
| 单个连续变量的分布 | 直方图配必要密度线、箱线图或经验分布图 | 饼图 |
| 异常值、离散程度 | 箱线图并按需要叠加个体点 | 仅报告均值 |
| 每组样本量小于 10 的组间比较 | 点图；或箱线图配 stripplot/抖动点 | 仅显示均值的柱状图 |
| 每组样本量不小于 10 的组间比较 | 箱线图、小提琴图配个体点，或带明确区间的点图 | 只有均值且不交代分布的柱状图 |
| 类别数量或占比 | 按值排序的横向柱状图、点图或堆叠柱状图 | 饼图、爆炸饼图、三维饼图 |
| 时间、剂量或有序参数趋势 | 折线图配必要误差带 | 用柱状图遮蔽连续趋势 |
| 两个连续变量的关系 | 散点图配必要拟合线、区间和相关统计量 | 把无序样本连成折线 |
| 分类自变量与连续结果 | 点图、箱线图、小提琴图或柱状图 | 用折线连接无连续含义的类别均值 |
| 多变量相关关系 | 相关热力图或散点矩阵 | 无筛选的高维平行坐标图 |
| 分类效果 | 混淆矩阵、ROC 或 PR 曲线 | 只给单一准确率 |
| 回归拟合与误差 | 真实值—预测值图、残差图和误差分布 | 只给一条平滑拟合曲线 |
| 矩阵或连续标量场 | 热力图、等高线图或云图并配色标 | 无色标的颜色编码、rainbow/jet 色图 |
| 空间格局 | 地图、空间分布图、等高线图或云图 | 与地理或空间位置脱节的装饰底图 |
| 多方案排名 | 三线表配柱状图或点图 | 雷达图堆叠 |
| 参数敏感性 | 参数—结果曲线或区间图 | 只给单个扰动点 |
| 多目标权衡 | Pareto 前沿 | 用任意加权总分掩盖权衡 |
| 收敛过程 | 目标值或误差—迭代次数曲线 | 只写“已经收敛” |
| 算法、机理或结构 | 流程图、几何图、原理图或结构图 | 软件界面、代码截图 |

图例类别或分组组合超过 12 个、单图承担多个不相干结论、图中主次无法辨认时，原则上按结论主题拆图，不得通过缩小字号或堆叠图例硬塞。单幅组合图原则上不超过 6 个子图。

### 3.3 必须主动拦截的误导性表达

1. 每组 `n < 10` 时不得只画均值柱；必须展示个体点，并优先使用点图或箱线图配个体点。
2. 原则上不使用双 Y 轴比较不同变量；容易制造由轴尺度决定的相关或分歧。应拆成共享 x 的上下子图，或在有依据时标准化后共轴比较。
3. 不使用饼图、三维柱状图、三维饼图、渐变装饰背景或过度艺术化图形。
4. 比例、数量或长度比较的数值轴原则上从 0 起；确需截断、断轴或对数轴时，必须显著标示并说明理由，不得夸大小差异。
5. 连续值以颜色编码时必须有色标及变量名、单位；不得使用感知不均匀的 rainbow/jet 色图。
6. 分类横轴不得用折线制造不存在的连续关系；只有类别有自然顺序且连线具有实际含义时方可使用。
7. 不得用单条平滑曲线、均值或汇总柱掩盖波动、异常值、样本量或不确定性。
8. 不得手工移动数据点、修改坐标、删去不利样本或更改标签以迎合结论。

## 4. 数据图的语义与统计要求

### 4.1 坐标、尺度和口径

- 坐标轴名称、单位、刻度、图例、色标、时间范围、样本范围、筛选口径和分面标签必须齐全。
- 可比较的多图必须统一坐标范围、色标范围、颜色语义、类别顺序和统计口径；确需不同尺度时，在图题或正文显式说明。
- 同一对象跨图保持同一颜色、线型或点型；同一视觉变量不得在不同图中表达相反含义。
- 最优点、基准值、目标线、阈值、可行域、置信区间或政策边界中凡与结论有关者，必须直接标注；标注不得遮挡数据。
- 散点过密时使用透明度、抽样、二维密度、六边形分箱或聚合，并说明抽样或聚合口径，不得让过绘制遮蔽结构。

### 4.2 不确定性与显著性

存在抽样、预测或参数不确定性时，应按任务使用误差棒、置信带、分布图、箱线图或区间表，不得只画确定性中心线。

只要图片包含误差棒、阴影区间、箱线或显著性符号，图题或紧邻正文必须写清：

- 误差或区间类型，例如 SD、SEM、置信区间或 IQR；
- 样本量 `n`，以及 `n` 是观测数、对象数还是重复次数；
- 使用的统计检验和多重比较校正；
- 显著性符号及阈值定义；
- 必要时说明独立重复、配对结构或重复测量设计。

不得混淆 SD、SEM 和置信区间，不得仅用星号替代效应量、区间和实际意义解释。

### 4.3 颜色与冗余编码

- 默认使用高对比、色盲友好的离散配色；连续量使用感知均匀的顺序色图，正负偏差或相对基准使用有明确中点的发散色图。
- 颜色只用于确有编码意义的图形，不用彩色标题、装饰线或背景制造层级。
- 不得只依赖红绿或单一颜色区分类别；重要类别同时使用线型、点型、明度、纹理、直接标签或分面等冗余编码。
- 黑白或低质量打印下必须仍能识别主要对象、趋势和结论。

## 5. 流程图、结构图与其它解释性图示

### 5.1 何时需要图示

涉及空间几何、方向向量、物理传递、网格划分、网络结构、多阶段流程、分支、循环、回退或多个模型组件时，原则上配置至少一幅与推导一致的几何图、原理图、结构图、网格图或流程图。简单关系用文字和公式已经足够清楚时，不为凑数量添加装饰图。

问题分析章可用总体技术路线图解释各问依赖；模型建立处使用几何、原理或结构图解释“模型如何工作”；求解处的流程图解释实际算法顺序；各类图不得放错职责位置。

### 5.2 图示内容要求

- 图中对象、箭头、变量、坐标、方向、边界、输入输出和正文术语必须与公式、算法步骤及实际计算一一对应。
- 阅读方向必须明确且直观；入口、出口、主线、分支和回流可辨。
- 判断节点必须写清判据或选择；分支标签贴近对应边且不侵入节点。
- 避免无标记交叉线、方向不明的折线、歧义连接和过长节点文字。
- 节点、箭头、连线、边标签之间必须保留独立净空，不得重叠、压线或遮挡。
- 多阶段算法的节点名称应与正文编号步骤一致；流程图只能辅助，不能替代输入、输出、文字和公式。

## 6. 论文叙事、位置、编号与图题

### 6.1 叙事闭环

所有图片必须遵循“前文引入并说明目的—呈现图片—后文解释主要发现和作用”。图片靠近首次引用位置，先在正文引用再出现，不得在多个章节重复使用同一结果图。

结果部分先给本问最终答案或核心判断，再按“核心结果图—必要精确值表—验证或诊断图”的顺序展开，不先堆叠大量中间图。正文紧随图后解释方向、数量级、原因、判断或决策含义，不得只写“由图可知结果良好”。

### 6.2 编号与图题

1. 图题置于图下，统一为“图 x  标题”，图号连续且正文引用一致。
2. 图题应能独立说明对象、指标、条件、情景、样本或数据口径；多面板图还需说明各面板差异。
3. 图题不得与图片主体分离，图片和图题不得跨页拆散；标题不得孤悬页末。
4. 图题字体、字号与通用论文字体规则执行 `PW-FMT-001`；图片内部中西文同样执行该规则，不保留绘图软件默认字体。
5. 图片文件名和稳定标签执行 `docs/standards/naming.md`。

## 7. 最终尺寸、布局与可读性

### 7.1 按最终显示尺寸生成

绘图阶段必须以论文中预计的实际显示宽度和高度设置画布、字号、线宽、点大小、箭头和图例。插入 Word/LaTeX 时只允许等比放置；若插入后尺寸明显改变并影响文字或线条层级，必须按新的最终尺寸重绘，不得依靠二次缩放补救。

普通横向单图或组合图默认以黄金比例为版式目标：实际显示内容框的高宽比 `H/W` 尽量接近 `0.618`，即宽高比约 `1.618:1`，推荐容许区间 `0.58—0.66`；竖向图相应使 `W/H` 接近 `0.618`。该比例针对整幅图，不要求每个子图单独满足。地图、正方矩阵、圆形场图、纵向流程图、全页多面板或由科学含义决定纵横比的图可偏离，但必须以清晰表达为先。

不得非等比拉伸图片以满足比例。应通过绘图画布、裁减无效留白、图例位置、子图重排或拆图调整。

### 7.2 字号、线条与多面板

- 图内关键文字在最终排版尺寸下原则上不小于 **9 pt**；坐标、图例、色标、标注和节点必须在正常打印尺寸下直接可读。
- 主线、辅助线、基准线、置信带和网格线必须有清楚层级，避免线宽、点型或透明度使主要结论失焦。
- 多子图优先使用 `1×2`、`2×2`、`2×3` 等整齐布局；子图等宽等高、基线对齐、间距一致。
- 多子图按阅读顺序统一标注“(a)”“(b)”等；面板字母使用统一的图坐标或版式机制对齐，不得逐个随意手摆导致漂移。
- 共享坐标、图例或色标时只保留一套，减少重复占位；同类图保持尺寸、字体、线宽、颜色和风格一致。
- 每张图必须在论文实际尺寸下完成一次阅读检查。若必须放大才能辨字，或无法一次顺序阅读主线，应重排、放大、拆图或删减文字。

## 8. 输出格式、分辨率与真实性

1. 线图、散点图、柱状图、误差图、流程图、结构图和一般热力图优先导出 PDF、SVG 或 EPS 等矢量格式。
2. 照片、遥感影像、像素场或无法矢量化的复杂栅格图使用 PNG 或 TIFF；正式数据图和示意图不得使用 JPEG。
3. 位图在论文最终插入尺寸下的有效分辨率原则上不低于 **300 dpi**；需要保留细节的影像可提高至 600 dpi。把低分辨率图片改写 DPI 标签或转格式不能增加真实清晰度。
4. 视觉自检前可导出 PNG 预览；正式图通过闭环后再导出矢量版、论文用位图和必要灰度预览。
5. 图片必须由最终数据、程序或已核对的模型定义生成。不得截取 MATLAB、Python、Excel、SPSS 等软件界面，不得手工修改图中数据、坐标或标签。
6. 关键图的正式产物、论文引用副本和必要预览按 `docs/standards/workspace-governance.md` 路由；图片属性和元数据不得暴露队员、学校、指导教师、赛区、用户名或本机路径。

## 9. 三层视觉自检闭环

### 9.1 语义层

逐图核对：

- 图型是否与论证目标和数据结构匹配；
- 样本量、分组、统计量、不确定性和显著性是否表达完整；
- 坐标截断、双轴、颜色、连线、三维透视等是否可能误导；
- 图片是否确实支持正文主张，是否存在过度结论；
- 图中口径、单位、对象、数值和模型名称是否与权威结果及正文一致。

### 9.2 形式层

逐图核对：

- 实际显示尺寸、比例、字体、字号、线宽、图号和图题；
- 坐标、单位、刻度、图例、色标、面板标签、误差说明和必要注释；
- 文件格式、有效分辨率、等比缩放和留白；
- 图表先引用后出现，图题与主体同页，正文有后续解释；
- 文件名、标签、元数据、匿名性和产物路由。

### 9.3 视觉层

每张正式图必须先渲染为可查看的 PNG 或页面预览，再同时完成可程序检查与人工或具备视觉能力的 Agent 读图复核：

1. 检查缺字、乱码、负号方框、文字越界、裁切和刻度标签重叠。
2. 检查图例、色标、标注、面板字母、节点、箭头、连线和边标签是否遮挡数据或彼此压线。
3. 检查多面板对齐、间距、视觉层级、阅读顺序和同类对象的颜色一致性。
4. 检查灰度或黑白预览，确认不依赖颜色仍可识别核心信息。
5. 检查主要结论能否在正常打印尺寸下一眼定位，是否存在过密、过空、主次颠倒或一图多论点。

任何一层失败都必须回到生成步骤修改、重新渲染并复查，不得仅在报告中记录后继续发布。

### 9.4 最终 PDF 复查

源图通过不等于论文中的图通过。发布前必须逐页渲染拟交付 PDF，并对每张图：

- 在论文实际排版尺寸和 100% 显示下各检查一次，必要时检查灰度打印；
- 核对实际比例、清晰度、留白、分页和上下文；
- 确认文字、节点、箭头、连线、图例、坐标和标注无重叠、遮挡、裁切、压线或歧义；
- 确认插入后没有被压缩、非等比拉伸或缩得过小；
- 确认正文引用、图题、数值、单位和结论与最终图一致。

图片、图题、分页或正文解释发生修改后，原视觉审校结论失效；必须重新渲染受影响页面，分页变化时重新检查全部页面。

## 10. 产物、证据与发布阻断

- 图片中的数据和事实主张必须满足 `WG-EVID-001`，并能追溯到 `04-results/` 的权威结果、明确推导或已核验资料。
- `06-paper/figures/` 只保存论文实际引用的副本，并能追溯到 `04-results/figures/`；不得把临时预览当作唯一证据或交付物。
- 摘要、正文、图、表、附录与机器结果中的数值、单位、对象、排序和舍入必须一致。
- 正文图片数量门禁与国奖竞争力评分由 `docs/standards/paper-quality-audit.md` 定义；不得通过拆分图号、重复图、装饰图或无意义多面板凑数。

出现下列任一情况时，`PW-FIG-001` 必须判为 `BLOCKED`：

1. 图片来源或关键数值不可追溯；
2. 使用误导性图型、尺度、颜色、统计量或手工修改数据；
3. 缺少坐标、单位、图例、色标、误差定义、样本量或关键图题信息，导致结论无法正确解释；
4. 最终 PDF 中存在影响阅读的乱码、模糊、过小字号、重叠、遮挡、裁切、压线或流程歧义；
5. 图片与正文、表格、公式、附录或机器结果不一致；
6. 未完成最终 PDF 的逐图复查，或修改后沿用失效的视觉审校结论。
