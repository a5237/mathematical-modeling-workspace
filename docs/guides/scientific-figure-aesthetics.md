# 科研图片审美参考使用指南

本指南说明如何在不改变科学语义的前提下，使用少量优质参考图校准科研图片的视觉语言。选图、编码、字号、输出与发布门禁只以 `docs/standards/paper-figures.md` 的 `PW-FIG-001` 为准；本指南不另设一套阈值。

## 1. 正确定位

参考图是审美锚点，不是图型模板、数据来源或论文证据。它主要帮助统一：

- 字体层级、轴标题、刻度与面板标签；
- 坐标轴、刻度线、边框和辅助网格；
- 低至中等饱和度且色盲友好的颜色；
- 主线、辅助线、点、误差棒与置信带的层级；
- 留白、边距、图例与注释密度；
- 多面板的对齐、间距、共享图例和阅读顺序。

参考图不得决定数据该如何汇总，不得迫使目标图改成相同图型，也不得成为使用平滑、三维、渐变、截断坐标或装饰元素的理由。

## 2. 使用流程

1. 先依据论证职责、用户要求、数据与模型原生结构完成图型和视觉编码决策。
2. 确定论文中的最终显示尺寸，再从 `resources/figure-style-library/manifest.csv` 选择少量与当前视觉问题相关的参考项。
3. 对每个参考项只提取可迁移的样式属性，例如“面板标签位置”“线—带层级”“图例留白”；同时写明不可复制的图型、数据和注释。
4. 将提取结果落实为当前项目的一套共享样式参数；同一组图片共用字体、颜色语义、线宽层级、面板标签和边距策略。
5. 用权威数据或模型定义重新生成目标图。参考图不得直接进入 `04-results/` 或充当正式图的底图。
6. 在最终显示尺寸下比较目标图与参考图，只检查视觉层级和一致性；语义、统计和真实性仍按 `PW-FIG-001` 独立复核。
7. 完成彩色、灰度、矢量/位图预览以及最终 PDF 读图检查。若审美调整损害可读性、真实性或科学含义，撤销该调整。

## 3. 参考选择方法

按“当前需要解决的视觉问题”选择参考，而不是机械寻找相同图型：

| 当前问题 | 优先观察的参考属性 |
|---|---|
| 折线多、置信带混乱 | 主次线宽、颜色明度、置信带透明度、直接标注或图例位置 |
| 散点与拟合线互相遮挡 | 点大小、描边、透明度、拟合线与区间的层级 |
| 误差棒图难以比较 | 类别排序、零线、点与区间对比、横向留白 |
| 分布图拥挤 | 个体点密度、箱线/小提琴层级、组间间距 |
| 热力图或等高线压过正文 | 感知均匀色图、色标尺寸、等值线密度、轴比例 |
| 科学三维图显得花哨 | 真实第三维、视角、投影、网格简化与色面层级 |
| 多面板不统一 | 面板尺寸、字母位置、共享元素、基线与边距 |

不存在合适参考时，直接依照 `PW-FIG-001` 作图，不为“像参考图”而强行套用不匹配的结构。

## 4. 项目记录

在项目 `00-admin/figure-selection-record.md` 的逐图决策单中填写：

- `style_reference_ids`：实际查看的参考项标识；
- `adopted_style_attributes`：本图采纳的字体、线、颜色、留白、图例或面板属性；
- `explicitly_not_copied`：未复制的图型、数据、模型、结论、注释或其它不适用元素；
- `final_size_comparison`：在最终尺寸下是否仍清楚、平衡、一致。

这些字段只记录设计依据，不替代数据来源、证据标识和三层审查结论。

## 5. 给绘图 Agent 的简洁指令

可在具体作图请求中附加：

> 先按数据与模型选择正确图型，再从 `resources/figure-style-library/` 选择少量参考图，只借鉴字体层级、轴线、配色、线点尺度、留白、图例、注释和多面板一致性。不要复制参考图的数据或结构，不要为匹配参考而改变合理的视觉编码。以最终显示尺寸渲染并按 `PW-FIG-001` 完成语义、形式、视觉和最终 PDF 检查。

## 6. 扩充参考库

新增参考项时须同时更新 `resources/figure-style-library/manifest.csv`，登记来源、使用边界、可学习属性和不可复制内容。只纳入在目标尺寸下仍清楚、无明显误导性编码、视觉层级稳定且来源可说明的图片；相似样例只保留更清楚的一项，避免参考库变成未经筛选的图片堆。
