# 数学建模优秀论文参考库

本目录集中保存数学建模竞赛的优秀论文及精读笔记。允许参考章节组织、模型表达、图表设计和验证方式，但禁止复制文字、公式、数据或结论。

建议每篇论文同时配一份阅读卡片或差距审计，记录题目类型、核心模型、求解方法、验证方式、可借鉴之处和不可直接复用的内容。

## 目录结构与命名规范

本参考库采用扁平化的“按模型分类”存储方式，所有论文和摘要直接存放在对应的大类文件夹中。
```
paper_library/
├── README.md
├── 01-运筹与决策优化/
│ ├── README.md
│ ├── [题目编号][描述].pdf
│ └── [题目编号][描述].md
├── 02-物理机理与仿真/
│ ├── README.md
│ ├── [题目编号][描述].pdf
│ └── [题目编号][描述].md
└── 03-统计推断与数据驱动/
├── README.md
├── [题目编号][描述].pdf
└── [题目编号][描述].md
```

**命名规范说明：**
- 大类文件夹名使用英文连字符 `-`，例如 `01-运筹与决策优化`。
- 文件使用下划线 `_` 连接编号与描述，如 `A196_无人机烟幕.pdf`。
- `.pdf` 文件为该论文的完整全文，包含完整推导、代码和图表。
- `.md` 文件为该论文的精读摘要，只保留核心算法、关键公式和代码实现陷阱。

## 主目录分类定义

本参考库按题型核心数学方法分为三大主目录：

- `01-运筹与决策优化/`：主要对应 B 题、D 题。涉及线性/整数规划、动态规划、图论、遗传算法、粒子群、差分进化及蒙特卡洛模拟。
- `02-物理机理与仿真/`：主要对应 A 题。涉及微分方程建模、物理反演、几何运动学、有限差分及空间几何概率。
- `03-统计推断与数据驱动/`：主要对应 C 题、E 题。涉及混合效应模型、回归分析、时间序列、机器学习集成模型及广义线性模型。

## 文件用途与检索指引

**PDF 完整论文：**
提供论文的完整章节、代码框架和结果可视化。适合需要参考完整结构、代码实现排版或验证方法时使用。

**MD 摘要笔记：**
提供该论文的核心模型、关键公式、代码避坑点和可迁移结构。适合需要快速提取某特定算法实现细节时使用。

**检索优先级：**
1. 进入对应算法大类，首先读取该目录下的子 README，确认是否包含你需要的算法。
2. 若需要快速提取某类算法的核心公式、具体参数设定或代码实现陷阱，优先在对应文件夹中查找对应的 `.md` 精读摘要。
3. 若 MD 摘要信息不足以支撑完整推理，或者需要参考整篇论文的逻辑架构、图表风格和完整代码结构，再翻阅对应的 `.pdf` 全文。

本库仅为参考源，所有生成代码必须经过实际运行验证。
