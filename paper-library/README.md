# 优质论文参考库

本目录集中保存数学建模优秀论文和阅读记录。允许参考章节组织、模型表达、图表设计和验证方式，但禁止复制文字、公式、数据或结论。

建议每篇论文同时配一份阅读卡片或差距审计，记录题目类型、核心模型、求解方法、验证方式、可借鉴之处和不可直接复用的内容。
