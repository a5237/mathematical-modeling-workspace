# A178：板凳龙碰撞检测与停止盘入研究（摘要）

## 核心模型体系
- **主要模型**：同心圆碰撞近似模型、几何碰撞判定模型。
- **关键算法**：变步长搜索、二分搜索（精确求解首次碰撞的临界时间）。
- **目标函数**：求得舞龙队不能再继续盘入的准确临界时间（即碰撞前一刻）。

## 关键实现与参数设定（代码避坑）
1. **近似定位**：先用同心圆几何模型快速定位碰撞的大致时间范围（约 410s 左右）。
2. **精确修正**：在 [400, 420] 秒区间内缩小步长（如 Δt = 0.0001s），精确碰撞时刻为 `412.4739s`。
3. **叉乘法**：碰撞判断模型采用**叉乘法**判断点是否位于三角形内部。如果内圈板凳顶点在外圈板凳三角形内部，则判定碰撞。

## 思路亮点/可复用结构
- **“粗粒度估计 -> 细粒度精准搜索”** 的两步走算法，在处理复杂物理模拟或碰撞检测时有非常高的工程实用价值。
