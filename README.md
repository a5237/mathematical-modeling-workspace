# 全国大学生数学建模大赛工作区

这是一个用于全国大学生数学建模大赛（CUMCM）的私人工作区，用于按项目组织赛题、数据、模型、结果、论文和交付材料。

## 目录约定

- `00-inbox/`：新收到、尚未归类的需求与附件。
- `projects/`：正式项目，采用 `<contest>-<year>-<problem>` 命名。
- `templates/`：可复用模板。
- `shared-tools/`：跨项目通用工具。
- `archive/`：历史归档，不作为当前项目来源。
- `paper-system/`：工作区的项目结构与命名规则。
