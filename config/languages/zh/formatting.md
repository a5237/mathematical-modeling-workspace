# 中文排版族

> 分派方式：当前项目赛事 profile 的 `profile.yaml` 声明 `language: zh` 时，本文件与 `docs/standards/paper-formatting.md` 共同构成排版权威；本文件只收"在中文下成立、换文字系统照做反而错"的条款。归属裁决执行 `WG-LAYER-001`。赛事专属取值（节名、编号样式、官方字号）仍归赛事 profile，不在此重述。

## 字体

1. 全部中文字符统一使用宋体，包括题目、标题、正文、摘要、关键词、图题、表题、表内文字、页眉页脚、参考文献和附录。
2. 中文标题强调时使用加粗宋体，不改用黑体、楷体、仿宋或微软雅黑。
3. 代码块外的中文标题与说明、公式中的中文说明均使用宋体。

## 字号叫法

4. 字号仍以 pt 为唯一标准；三号、四号、小四、五号等中文字号名只是同一制度在中文排版里的等价叫法，按 `docs/standards/paper-formatting.md` 表格中的对照使用，全篇英文时直接取 pt 值。

## 段落与引用措辞

5. 自然段分隔用首行缩进（默认 2 字符）、段前段后为 0。
6. 图、表题注词用"图 x""表 x"；正文引用公式写作"式（x）"。
