# 审校分级

- `critical`：伪造或不可追溯结果/引用；程序无法运行或与论文不符；泄露身份；违反竞赛硬性规则；遗漏题目要求的核心输出。
- `major`：摘要与正文数值冲突；关键约束、单位、验证或参数缺失；每问分析不足两类；关键文献未核验；交付材料不完整。
- `minor`：不改变结论的编号、措辞、图表可读性或局部格式问题。
- `note`：可选改进，不影响提交。

报告每项包含：`id`、`severity`、`location`、`finding`、`evidence`、`required_fix`、`verification`。先列阻断项，再给总分。存在 `critical` 或 `major` 时，结论只能是 `BLOCKED`。

建议百分制权重：问题覆盖 15，模型合理性 20，求解与可复现性 20，结果与验证 20，论文表达 10，引用真实性 5，格式匿名与交付 10。硬性违规优先于分数。
