## 使用门禁

1. 建模和编码前，必须先查阅本索引及匹配的算法说明，并在项目 `03-models/model-selection.md` 记录候选算法、适用性核验和选择理由。
2. 资源库中存在适用算法时，主模型与代码实现应优先采用或基于该算法；只有资源库不覆盖、适用条件不满足，或外部方法在本题指标上有明确优势时，才可改用库外算法，并记录偏离理由和验证方案。
3. 选用前必须核对问题目标、假设、数据类型与规模、约束、依赖、评价指标和验证方式。不得仅因算法在库中就机械套用。
4. 每道子问题最多采用两个独立的主模型体系；同一物理机制的不同精度展开按一个模型族计数。基准模型、消融和验证对照不计入主模型数量，但不得伪装成额外主模型堆砌。
5. 文档中的代码是实现参考，必须按项目数据、接口、边界条件和依赖改写并真实运行；不得直接把示例输出当作项目结果。
6. 文档中的文献条目和方法说明不是已核验的论文证据。实际引用前必须打开原始来源，并登记到项目 `05-evidence/literature-ledger.csv`。
