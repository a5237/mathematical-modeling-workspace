# 复用资源

- `algorithm-library/`：建模和编码时优先查阅的算法说明、适用条件与代码参考；从 `index.md` 路由，只加载匹配类别。
- `templates/`：未填写的论文、报告和清单模板。
- `paper-library/`：优秀论文与阅读记录，仅供方法和表达参考。
- `figure-style-library/`：合成科研图审美参考、使用边界与索引；只指导视觉语言，不作为数据、模型或证据来源。

当前项目的正式代码、运行结果、论文、引用台账和交付物必须留在项目目录，不能以资源库副本作为权威来源。算法库示例必须按项目改写并运行，文献条目必须独立核验后才能引用。
