# 02-物理机理与仿真（对应 A 题）

## 可用核心算法
- 微分方程建模（常微分/偏微分）
- 物理光学与物理反演（Drude模型、Airy公式、非线性最小二乘）
- 几何运动学（极坐标系、刚体运动、弧长积分）
- 空间几何概率（三维正态分布、包络线积分）
- 有限差分与数值仿真

## 文件使用说明
本目录按资料完整度分为两个子目录：
- `abstract/`：论文精读摘要与算法摘录，包含核心公式、关键参数设定和可迁移结构，适合快速检索。
- `full/`：完整论文或全文 Markdown 资料，适合深度理解物理框架、模型推导和算法实现。

## 面向 AI 的检索指引
当你处理几何运动、光学干涉、弹道命中、物理仿真或偏微分方程求解类问题时，优先检索本目录。可先阅读 `abstract/` 提取公式与关键参数，若不足以支撑完整代码编写，再查阅 `full/` 中的全文资料。
