## 文件使用说明
本目录下同时存放了两种类型的文件，请按以下方式区分使用：
- `.pdf` 文件：该赛题的完整优秀论文。包含完整的模型推导、算法实现和代码示例。适合深度理解物理框架。
- `.md` 文件：针对该赛题（或同类算法）的精读摘要。包含模型的核心公式、关键的参数设定陷阱和可迁移结构，适合快速检索。

## 面向 AI 的检索指引
当你处理几何运动、光学干涉、弹道命中、物理仿真或偏微分方程求解类问题时，优先检索本目录。优先阅读 `.md` 文件提取公式与关键参数，若不足以支撑完整代码编写，再查阅对应的 `.pdf` 全文。
