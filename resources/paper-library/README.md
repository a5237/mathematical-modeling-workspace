# 优质论文参考库

本目录集中保存数学建模优秀论文、阅读记录以及单独标识的格式排版样例。允许按登记角色参考章节组织、模型表达、图表设计、验证方式或版面布局，但禁止复制文字、公式、数据、图表、代码或结论。

建议每篇论文同时配一份阅读卡片或差距审计，记录题目类型、核心模型、求解方法、验证方式、可借鉴之处和不可直接复用的内容。

正式写作前必须按 `docs/guides/pre-writing-learning.md` 实际阅读至少 2 篇同类型优秀论文，并把结构学习结果记入项目 `00-admin/pre-writing-learning.md`。范文只用于学习结构、论证和图表叙事；禁止复制文字、公式、数据、图表或结论，也不得因阅读范文就自动把它列为正式参考文献。
