# 格式与排版参考

本目录保存跨题型的论文格式与排版样例，只用于学习视觉层级和版面组织，不作为模型、算法、数据、结论或正式引用来源。

## 赛事隔离

样例按赛事 profile 分子目录存放，**结构学习只能取当前项目赛事的子目录**：

| 子目录 | 赛事 | 对应 profile | 语言与页数特征 |
|---|---|---|---|
| `cumcm/` | 全国大学生数学建模竞赛 | `config/contests/cumcm/` | 中文论文，正文不设总页数上限 |
| `mcm-icm/` | MCM/ICM（COMAP 美赛） | `config/contests/mcm-icm/` | 英文论文，整个提交 PDF 25 页封顶（AI 使用报告不计页） |

跨赛事样例只可用于数学方法与论证逻辑学习，不得计入 `PWL-GATE-001` 要求的结构学习范文数量；判定口径以 `docs/guides/pre-writing-learning.md` §2 为准。

## 预处理入口

- 低 token 检索与视觉索引：[cumcm/processed/README.md](cumcm/processed/README.md)、[mcm-icm/processed/README.md](mcm-icm/processed/README.md)，包含章节索引、逐页文字、插图/表格索引、整页图和视觉总览。
- 默认先读取目标样例的 `outline.md`、`full-text.md` 或 `visual-index.md`，再按需打开单页或单幅图片，避免重复加载整份 PDF。
- 原 PDF 始终是权威来源；自动提取的文字、标题与裁图仅用于定位和版式学习，不能替代原文核验。

## 使用边界

1. 本目录样例的唯一预设角色是“格式排版参考”，不得计入同类型优秀论文的内容学习数量，除非项目学习记录另行说明并完成真实阅读。
2. 实际写作、排版与图片必须分别服从当届官方规则、当前项目赛事的样例子目录、`docs/standards/paper-writing.md`、`docs/standards/paper-formatting.md` 和 `docs/standards/paper-figures.md`；样例与正式规范不一致时，不得以样例覆盖正式规范。
3. 样例使用的具体字体不自动继承：`cumcm/` 样例为中文排版（宋体与 Times 系），`mcm-icm/` 样例为英文 LaTeX 排版（Computer Modern、URW Palladio、TeX Gyre Termes 等）；本工作区仍按 `docs/standards/paper-formatting.md` 与当前 profile 规定执行。
4. 可提取版式规律和图表叙事策略，但不得复制样例文字、公式、数据、图表、代码、结论或未经核验的文献。
5. 在项目 `00-admin/pre-writing-learning.md` 中使用本目录样例时，来源角色应登记为“格式排版参考”，并在 `path_or_source` 中写明赛事子目录路径，以便核对结构学习样本的赛事归属。
