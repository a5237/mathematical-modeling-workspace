## 文件使用说明
本目录按资料完整度分为两个子目录：
- `abstract/`：论文精读摘要与算法摘录，包含核心公式、关键参数设定和可迁移结构，适合快速检索。
- `full/`：完整论文或全文 Markdown 资料，适合深度理解模型推导、算法实现和代码示例。

## 面向 AI 的检索指引
当你处理资源分配、生产决策、路径规划、动态网络或调度类问题时，优先检索本目录。可先阅读 `abstract/` 提取公式与关键参数，若不足以支撑完整代码编写，再查阅 `full/` 中的全文资料。
